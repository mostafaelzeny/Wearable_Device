ESP32 MAX30102 Wearable Vitals System

This project reads heart-rate and estimated SpO2 from a MAX30102 sensor using an ESP32, publishes the data through MQTT, and displays it in a browser dashboard.

MAX30102Red + IR optical sensor
ESP32I2C, BPM, SpO2, WiFi
MosquittoMQTT + WebSockets
DashboardBrowser GUI
Medical warning: this is for learning and prototyping. It is not a medical device. The MAX30102 datasheet does not include a final medical SpO2 equation, so this project uses an estimated ratio-of-ratios calculation that needs calibration against a real pulse oximeter.

Network And MQTT

The ESP32 publishes normal MQTT to the PC:

host: PC_IP_OR_HOSTNAME
port: 1883
topic: wearable/vitals

The browser dashboard connects through MQTT over WebSockets:

url: ws://localhost:9001
topic: wearable/vitals
Browsers cannot connect to raw MQTT TCP on port 1883. That is why Mosquitto also opens WebSockets on port 9001.

Mosquitto Config

mosquitto-websockets.conf contains:

listener 1883 0.0.0.0
allow_anonymous true

listener 9001 0.0.0.0
protocol websockets
allow_anonymous true

MQTT Payload

Normal data:

{"bpm":72,"spo2":97,"finger":true,"uptime_ms":123456}

No finger:

{"bpm":0,"spo2":0,"finger":false,"uptime_ms":123456}

LED Tuning

If the signal is weak, increase LED currents carefully:

writeRegister(REG_LED1_PA, 0x30);
writeRegister(REG_LED2_PA, 0x30);

If the readings saturate or become unstable, reduce them:

writeRegister(REG_LED1_PA, 0x18);
writeRegister(REG_LED2_PA, 0x18);

BPM And SpO2 Algorithms

BPM

The BPM calculation uses the IR signal:

  1. Track a slow DC baseline.
  2. Subtract the baseline to get the pulsatile waveform.
  3. Detect upward threshold crossings.
  4. Measure time between valid beats.
  5. Average the recent valid BPM values.
static const uint16_t MIN_BEAT_MS = 300;   // 200 BPM max
static const uint16_t MAX_BEAT_MS = 1500;  // 40 BPM min
static const float MIN_BEAT_THRESHOLD = 18.0f;

SpO2

The project uses the common MAX3010x ratio-of-ratios estimate:

R = (ACred / DCred) / (ACir / DCir)
SpO2 ~= 110 - 25 * R

The sketch adds a calibration offset:

static const int SPO2_CALIBRATION_OFFSET = 6;

Final calculation:

int spo2 = (int)round(110.0 - (25.0 * ratio)) + SPO2_CALIBRATION_OFFSET;

SpO2 Timing

static const uint16_t SPO2_WINDOW = SAMPLE_RATE_HZ * 4;
static const uint32_t SPO2_SETTLE_MS = 8000;
static const uint32_t SPO2_UPDATE_MS = 5000;
  • SpO2 uses a 4-second data window.
  • The sketch waits 8 seconds after finger detection before accepting SpO2.
  • SpO2 updates every 5 seconds.
  • BPM still updates every 1 second.

Calibration

Use a reference pulse oximeter:

new_offset = reference_spo2 - sketch_spo2

Example:

reference oximeter = 97
sketch = 91
offset = 6

Signal Quality Rejection

The sketch rejects SpO2 windows with weak contact, saturation, unstable baseline, weak AC signal, or impossible red/IR ratios.

Normal Portable Setup On Any PC

Use this sequence when moving the same system to another computer.

1. Install Packages

sudo apt update
sudo apt install mosquitto mosquitto-clients avahi-daemon
sudo systemctl enable --now avahi-daemon

2. Start Mosquitto Manually

From the project folder:

mosquitto -c mosquitto-websockets.conf -v

Keep this terminal open. This is the simplest method and works on any PC with Mosquitto installed.

3. Test MQTT

Terminal 1:

mosquitto_sub -h localhost -t wearable/vitals

Terminal 2:

mosquitto_pub -h localhost -t wearable/vitals -m '{"bpm":72,"spo2":97,"finger":true}'

4. Configure The ESP32 Sketch

hostname
hostname -I

Edit:

static const char *MQTT_HOSTNAME = "your_hostname";
static const char *MQTT_FALLBACK_IP = "your_pc_ip";

5. Open The Dashboard

On the same PC:

ws://localhost:9001

From another device:

ws://YOUR_PC_IP:9001

Troubleshooting

MQTT Connection Refused

systemctl --user status mosquitto-wearable.service --no-pager
systemctl status mosquitto --no-pager
ss -ltnp | grep -E '1883|9001'

Dashboard Does Not Connect

  • Use ws://localhost:9001 on the same PC.
  • Use ws://PC_IP:9001 from another device.
  • Check that Mosquitto is listening on port 9001.

ESP32 Cannot Connect To MQTT

  • Make sure ESP32 and PC are on the same network.
  • Check MQTT_HOSTNAME and MQTT_FALLBACK_IP.
  • Check that Mosquitto is running.
  • Check firewall settings for ports 1883 and 9001.

Hostname Resolution Problems

sudo apt install avahi-daemon
sudo systemctl enable --now avahi-daemon
getent hosts "$(hostname).local"

If hostname discovery still fails, use the fallback IP in the sketch.

No Finger Detected

The threshold is:

static const uint32_t FINGER_THRESHOLD = 50000;

Reduce it if your raw signal is lower. Increase it if false detection happens.

SpO2 Stays At 0

  • Wait through the initial settling time.
  • Keep your finger still.
  • Do not press too hard.
  • Shield the sensor from strong light.
  • Adjust LED currents if needed.

SpO2 Is Stable But Too Low Or Too High

static const int SPO2_CALIBRATION_OFFSET = 6;
offset = reference_spo2 - sketch_spo2

BPM Is Too High

Increase the threshold:

static const float MIN_BEAT_THRESHOLD = 30.0f;

BPM Is Always 0

Decrease the threshold or increase LED current slightly:

static const float MIN_BEAT_THRESHOLD = 12.0f;

Security And Medical Notes

Security

The local Mosquitto config uses:

allow_anonymous true

This is convenient for a local prototype, but not secure on public networks.

  • Do not expose ports 1883 or 9001 to the internet.
  • Use username/password for a real deployment.
  • Restrict access to your local network.
  • Use TLS if the data leaves your private network.

Medical Accuracy

Commercial wearables use calibrated algorithms, motion rejection, optical calibration, temperature compensation, and clinical validation. This project does not. Do not use it to make medical decisions.
